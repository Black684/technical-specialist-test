# ANOMALIES

## Обнаруженные проблемы
- Обнаружено 4 полностью дублирующиеся строки. Это выяснилось при анализе содержимого `review.csv`.
- Найдены повторяющиеся ID (`c_001075`, `c_001049`, `c_001050`), хотя идентификаторы компаний должны быть уникальными.
- Обнаружены 2 записи без ID и 3 записи с пустыми обязательными полями (`name`, `category`, `city` или `address`).
- Обнаружена вероятная опечатка в названии города — «Санкат-Петербург».
- Во время загрузки данных выяснилось, что в поле `rating` встречается значение `N/A`, которое не соответствует числовому типу PostgreSQL. Для корректной загрузки такие значения были преобразованы в `NULL`.

## Сравнение с исходной выгрузкой
При сравнении `review.csv` с исходными JSON-файлами обнаружилось, что:
- 196 ID присутствуют только в `review.csv`;
- 988 ID из исходной выгрузки отсутствуют в `review.csv`.

### Вывод
Вероятнее всего, `review.csv` не является обновлением исходной базы, а представляет собой отдельную или частичную выгрузку компаний.
