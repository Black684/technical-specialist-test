# ANOMALIES

## Обнаруженные проблемы

* Обнаружено **4 полностью дублирующиеся строки**. Обнаружено с помощью поиска полных дубликатов в `review.csv`.
* Повторяются **ID**: `c_001075`, `c_001049`, `c_001050`. Обнаружено подсчётом количества одинаковых значений поля `id`.
* Найдены **2 записи без ID**. Обнаружено проверкой обязательного поля `id`.
* Найдены **3 записи с пустыми обязательными полями** (`name`, `category`, `city` или `address`). Обнаружено проверкой обязательных полей на пустые значения.
* Обнаружена вероятная опечатка в городе: **«Санкат-Петербург»**. Обнаружено при просмотре уникальных значений поля `city`.
* Обнаружено значение **`N/A`** в поле `rating`. Выявлено во время загрузки данных в PostgreSQL: база не смогла преобразовать строковое значение `N/A` в числовой тип `NUMERIC`, поэтому такие значения были заменены на `NULL`.

## Сравнение с исходной базой

* В `review.csv` обнаружено **196 ID**, отсутствующих в исходных JSON-файлах. Обнаружено сравнением множеств идентификаторов из `review.csv` и исходной выгрузки.
* В `review.csv` отсутствует **988 ID** из исходной базы. Обнаружено тем же сравнением идентификаторов.

## Вывод

Вероятно, `review.csv` является отдельной или частичной выгрузкой компаний, а не обновлением исходного набора данных.
